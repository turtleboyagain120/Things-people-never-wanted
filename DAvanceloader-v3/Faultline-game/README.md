# How to Use FAULTLINE

A 2.5D parkour shooter HTML5 game. Currently in **Beta 1**.

---

## Quick Start

### Option 1: Clone with Git (Recommended)

**Requirements:** Git installed on your system

```bash
git clone https://github.com/turtleboyagain120/FAULTLINE.git
cd FAULTLINE
```

Then open `index.html` in your web browser:
- **Windows:** Double-click `index.html` or right-click → Open with → Your Browser
- **Mac:** Double-click `index.html`
- **Linux:** Open terminal → `firefox index.html` (or your browser)

---

### Option 2: Download ZIP

1. Go to [github.com/turtleboyagain120/FAULTLINE](https://github.com/turtleboyagain120/FAULTLINE)
2. Click **Code** → **Download ZIP**
3. Extract the `.zip` file to a folder
4. Open the extracted folder
5. Double-click `index.html` to play

---

## Playing the Game

Once `index.html` opens in your browser:

- **Controls:** Check the in-game controls menu
- **Gamepad Support:** Connect a controller for the full parkour shooter experience
- **Mouse/Keyboard:** Also supported as fallback

---

## Updating (Git Users Only)

To get the latest updates:

```bash
cd FAULTLINE
git pull origin main
```

Then refresh your browser to play the latest version.

---

## Troubleshooting

### Game won't load
- Try a different browser (Chrome, Firefox, Edge, Safari)
- Clear your browser cache: `Ctrl+Shift+Delete` (Windows) or `Cmd+Shift+Delete` (Mac)
- Make sure JavaScript is enabled in your browser

### Controls not working
- Try keyboard first, then gamepad
- Check if your gamepad is properly connected

### Slow performance
- Close other browser tabs
- Lower your browser window resolution
- Try a different browser
