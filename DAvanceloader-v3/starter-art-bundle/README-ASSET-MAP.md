# Asset Map

This guide explains what the starter SVGs are useful for. The bundle is not connected to the game code, so these files are safe references for forks, mockups, profile art, README art, or future sprite work.

## Player Art

- `cyan-runner.svg`
- `cyan-runner-air-strafe.svg`
- `cyan-runner-slide.svg`
- `cyan-runner-dash.svg`

Use these to study the player silhouette style: bright cyan outline, dark inner body, simple readable limbs, and motion streaks. They are good references if you want to build a player sprite sheet later.

## Enemy Art

- `red-soldier.svg`
- `orange-elite.svg`
- `turret.svg`
- `boss-twin.svg`
- `boss-core.svg`

Red should read as the normal threat. Orange should read as a stronger pressure enemy. Boss art can mix cyan and red so it feels connected to the player but still dangerous.

## Weapons

- `ar-rifle.svg`
- `shotgun.svg`
- `smg.svg`
- `pistol.svg`

These are prop references. They are intentionally simple so they can be scaled down. For actual gameplay sprites, keep the barrel direction readable and avoid tiny decorations that disappear in motion.

## Pickups And UI

- `heart-icon.svg`
- `shield-icon.svg`
- `coin-pickup.svg`
- `power-cube.svg`
- `ammo-crate.svg`
- `armor-shard.svg`
- `combo-badge.svg`
- `button-prompt-a.svg`
- `button-prompt-rt.svg`
- `gamepad-diagram.svg`

These are best for menus, HUD mockups, guides, README screenshots, or future UI experiments. Keep pickup icons bright because players need to recognize them quickly.

## Effects

- `bullet-trail.svg`
- `hit-spark.svg`
- `explosion-ring.svg`
- `smoke-puff.svg`
- `rain-streaks.svg`
- `mild-hit-drops.svg`

Effects should be short, readable, and not too noisy. Use these as references for animation frames or canvas particle colors.
