# Remix Ideas

This guide is a pile of starter ideas for people who find FAULTLINE and want to make something from the art bundle.

## Easy Ideas

- recolor `cyan-runner.svg` into a red rival
- make `orange-elite.svg` blue for a shield-only enemy
- turn `heart-icon.svg` into half-heart versions
- make coin variants from `coin-pickup.svg`
- use `warning-sign.svg` as a level hazard marker
- put `faultline-logo.svg` at the top of a fan page

## Medium Ideas

- make a 6-frame run cycle from `cyan-runner.svg`
- make a 6-frame slide animation from `cyan-runner-slide.svg`
- make a red enemy patrol sheet from `red-soldier.svg`
- make pickup animations by rotating `power-cube.svg`
- make a boss weak spot animation from `boss-core.svg`
- combine `rain-streaks.svg` and `skyline-tile.svg` for a title card

## Bigger Ideas

- build a full controller guide screen from `gamepad-diagram.svg`
- create a “new player tutorial” poster using the prompts and icons
- build a boss poster with `boss-twin.svg`, `boss-core.svg`, and `explosion-ring.svg`
- create a fan-made level theme using the rooftop prop files
- turn the effects into a small particle reference sheet

## Good Rule

Make one useful thing at a time. If it looks good small, fits the colors, and someone can remix it, it belongs in the bundle.
