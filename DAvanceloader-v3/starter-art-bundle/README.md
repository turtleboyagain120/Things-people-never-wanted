# FAULTLINE Starter Art Bundle

This folder is for players, modders, and anyone who wants to fork FAULTLINE and make their own art.

None of these files are loaded by the game. They are safe starter assets you can copy, remix, recolor, or use as reference art.

## Style Notes

FAULTLINE's look is brutalist rooftop action:

- dark concrete shapes
- cyan player glow
- red enemy glow
- orange elite/boss accents
- simple silhouettes
- sharp neon outlines
- readable shapes that work small

These are starter-grade vector files. That means they are meant to be useful, readable, and easy to edit, not locked-down final production sprites.

## How To Use

Open any SVG in a browser, vector editor, or code editor. You can recolor the main glow by changing these colors:

- Cyan player: `#4df7ff`
- Red enemy: `#ff2d55`
- Orange elite: `#ff8a2a`
- Concrete: `#303942`
- Dark background: `#061116`

If you fork the game, you can keep these as concept art, turn them into sprites, or use them as UI icons.

Good remix ideas:

- turn the player poses into a sprite sheet
- recolor enemies for new factions
- use props like vents, antennas, and water towers to decorate generated levels
- use `button-prompt-a.svg`, `button-prompt-rt.svg`, and `gamepad-diagram.svg` in a controls screen
- combine `hit-spark.svg`, `explosion-ring.svg`, `smoke-puff.svg`, and `mild-hit-drops.svg` into bigger effects
